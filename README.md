# The Great Estate Events

A single-file static schedule for The Great Estate festival weekend.

## Publish with GitHub Pages

1. Create a public GitHub repository, for example `great-estate-events`.
2. Upload `index.html` and `.nojekyll` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Set **Branch** to `main` and folder to `/ (root)`, then save.
6. Wait a minute or two for GitHub Pages to publish.

Your site should be available at:

```text
https://YOUR-GITHUB-USERNAME.github.io/great-estate-events/
```

## Features

- Search by artist, workshop, venue, genre or notes.
- Filter by day and venue.
- Hide all-day events.
- Star events and show starred-only.
- Stars persist per browser using `localStorage`.
- Copy a starred-link to share selected events.
- Fully static: no build step, backend or dependencies.
